# Ночной эфир

**[Скачать игру — NochnoyEfir.exe](https://github.com/detanetov/ne-gasi-svet-updates/raw/main/download/NochnoyEfir.exe)**

Один файл, установка не нужна. Если Windows покажет «Windows защитил ваш компьютер» — нажми «Подробнее», потом «Выполнить в любом случае».

Обновления игра скачивает сама при каждом запуске.

---

Служебное: `version.json` — номер последней версии и контрольные суммы файлов, `releases/<версия>/` — файлы игры, `download/` — программа целиком.
