# Не гаси свет — обновления

Отсюда игра скачивает обновления при каждом запуске.

- `version.json` — номер последней версии и список файлов с контрольными суммами SHA-256.
- `releases/<версия>/` — файлы игры этой версии.

Игра сравнивает версию, скачивает только изменившиеся файлы, проверяет каждый по SHA-256 и только потом переключается на новую версию. Если связи нет, запускается уже установленная версия.
